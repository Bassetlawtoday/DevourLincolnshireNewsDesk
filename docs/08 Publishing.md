# Publishing

NewsDesk publishing outputs are generated from the normalised `Story` model by
the shared `StoryEngine` and channel formatters.

Council stories use a controlled display adapter so readable UK dates reach
Website Article, Facebook Post and Newsletter Copy without changing stored
timestamps. Council Story Packs follow the established ZIP convention and
include generated copy, source details, metadata, article text, summary and a
usable official source image where one is available.

Facebook ingestion is not implemented.
